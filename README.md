# Pros and Cons of Using TabICL with the KDD Cup 98 Data

A short white paper by Dean Abbott (Abbott Analytics). It tests TabICL, a tabular foundation model, against XGBoost, logistic regression, neural nets, kNN and Naive Bayes on the KDD Cup 1998 donor data. The models are scored with standard metrics and with cumulative net revenue.

**Read it:** https://abbottanalytics.github.io/tabicl_kdd98/

This repository holds the published page: `index.html`, one self-contained file, and `preview.png`, the image for link previews. Claude Opus 5.5 ran the analyses, built the charts and tables, and suggested reporting insights. Dean Abbott edited all final content and approved it.
